What every entry carries

An entry is a fact only when its verifier passes. Until then it is a sourced claim, and it says so.

∑

Exact definition

The variant, its direction and units, so that two tables quoting "the same constant" can be told apart.

§

Primary source

A citation with a verbatim quote and date. A superseding value must be strictly better, for the same variant.

✓

Certificate

Where one exists, a checkable object and the command that verifies it, in exact arithmetic.

↗

Superseded chain

Every earlier value is kept, in order. The history is kept, not just the leader.

◐

Provenance

Who set the value. Recorded for 413 entries so far: 196 human, 115 AI system, 102 human with AI.

≡

Aliases

The names benchmarks and papers use for the same variant, mapped to one id.
